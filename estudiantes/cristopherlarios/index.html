Lo que aprendí (y enseño) en el curso

  1. Instalación y configuración: identidad con git config --global user.name.
  2. Primer repositorio: git init y los estados untracked, modified, staged y unmodified.
  3. Ciclo de vida: editar → git status → git add → git commit.
  4. .gitignore: nunca subir secretos, logs ni temporales.
  5. Ramas: experimentar sin romper main con git switch -c.
  6. Fusiones y conflictos: aparecen cuando dos ramas cambian la misma línea.
  7. Historial: log, diff, revert, reset, reflog y stash; nada se pierde.
  8. Remotos y colaboración: fork, upstream, fetch, pull, push y pull requests.
